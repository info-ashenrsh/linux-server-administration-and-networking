# Bash Scripts

These scripts are learning examples. Read each script before running it.

## Make scripts executable

```bash
chmod +x scripts/*.sh
```

## Run

```bash
./scripts/server-information.sh
./scripts/server-update.sh
./scripts/nginx-install.sh
```

The scripts use `sudo` for administrative operations. Review prompts and package changes. Do not run scripts from an untrusted source on a production server.
